## Short Voiceover Script

Most job applications make you jump between tabs, tools, and old documents.

CoverCraft keeps the work on the job page, where the role context already exists.

From one compact extension panel, you can generate a tailored cover letter, save a manual draft without using AI, tailor a resume draft, and ask follow-up questions in the same saved session.

Then the dashboard becomes the control center: previous companies, generated drafts, profile context, settings, sync, model usage, and account state all stay reusable.

CoverCraft is my Chrome extension for faster, cleaner job applications.

## Editing Notes

- Keep each screenshot on screen for 5-7 seconds.
- Use slow zooms only, around 103-108%, so the UI remains readable.
- Crop portrait extension screenshots into the center of a 4:5 frame with a blurred or darkened duplicate behind them.
- Use dashboard screenshots full-width with a small top/bottom crop if needed.
- Keep captions short and high contrast.
- Avoid showing private API keys, private profile details, or real personal contact info.
- Keep background music low under voiceover, around -22 to -28 LUFS equivalent.

## LinkedIn Post Copy

I built CoverCraft, a Chrome extension that turns a live job page into a reusable application workspace.

It helps with:

- tailored cover letters
- manual cover-letter drafts without AI
- resume tailoring
- follow-up Q&A
- saved company/application sessions
- reusable profile context
- provider, sync, and model-usage controls

The goal is simple: reduce the repetitive work around job applications without losing the context that makes each application specific.
